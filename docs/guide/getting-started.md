# Getting started

Install and run:

```bash
npm install
npm run dev -- D:\notes
```

The server only listens on `127.0.0.1`, so nobody else on the network can open it.

```ts
export function greet(name: string): string {
  return `Hello, ${name}!`; // highlighted
}
```
